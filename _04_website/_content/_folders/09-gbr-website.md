This website has been entirely vibe-coded, via ChatGPT 5.6 Sol.

Below is the original design mock-up I supplied to Sol. I made it in
MS Paint, I didn't even bother to save it as an image, I took a screenshot
of it not caring for capturing Paints UI elements and pasted it into a new
chat with Sol along with my prompt instructions.

It took one single day to build.

What do we get for that day?

A media player, with genre switching, audio visualisation, live-lyric displays.

Interactive reference media, showing details about the playing song on demand.

A timeline/educational set of story boards which detail the processes used (the
text within these tabs was written by myself, and certainly not in a single day,
but all the functionality that enabled me to get on with that writing and documenting
I built with Sol in that day).

We have embedded media in the form of Spotify playlists, url linking to the sources
of inspiration I used and tools/models deployed.

Maybe we even have a secret hidden feature somewhere? Who knows... I switched off whilst
Sol was writing that bit.
